# 🍧 MR YISSTIV - Sistema de Gestión de Cholados

Sistema completo de gestión para MR YISSTIV Cholados, desarrollado como proyecto del SENA.

## 📋 Características

- ✅ **Gestión de Usuarios**: Registro, login y autenticación
- ✅ **Catálogo de Productos**: Cholados, helados, postres y combos
- ✅ **Carrito de Compras**: Agregar productos y gestionar cantidades
- ✅ **Pedidos**: Gestión completa de pedidos y estados
- ✅ **Múltiples Métodos de Pago**: Efectivo, Nequi, DaviPlata (Patrón Strategy)
- ✅ **Reservas y Favoritos**: Sistema de fidelización
- ✅ **Domicilios**: Gestión de entregas

## 🛠️ Tecnologías

- **Backend**: Java 8, JDBC
- **Base de Datos**: MySQL 8.0
- **IDE**: Eclipse IDE 2018
- **Servidor**: XAMPP (Apache + MySQL)
- **Patrones de Diseño**: Strategy, DAO, MVC
